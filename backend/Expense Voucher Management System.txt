Expense Voucher Management System
Full Stack Developer Internship Assignment
1. Introduction
ABC Company currently manages employee expense vouchers manually. Employees fill
out expense vouchers, obtain approval from the Director, and submit them to the
Accounts Team for reimbursement. This manual process is time-consuming, difficult to
track, and lacks transparency.
The objective of this assignment is to develop a web-based Expense Voucher
Management System that digitizes the complete voucher creation, approval, and
tracking process.
The application should allow employees to create expense vouchers, enable the
Director to review and approve or reject them, and allow the Accounts Team to monitor
all vouchers for payment processing.
This assignment is designed to evaluate a candidate's ability to build a real-world fullstack application, including frontend development, backend development,
authentication, authorization, database design, REST APIs, file uploads, validation, and
clean software architecture.
2. Objective
The application should:
• Replace the manual voucher approval process.
• Allow employees to submit expense reimbursement requests.
• Allow the Director to approve or reject vouchers.
• Allow the Accounts Team to view all vouchers for reimbursement processing.
• Allow employees to track the status of their submitted vouchers.
• Maintain a centralized repository of all vouchers.
• Ensure only authorized users can access relevant information based on their
role.
3. User Roles
The application must support the following three user roles.
3.1 Employee
Employees are responsible for creating and submitting expense vouchers.
Employees should be able to:
• Login to the application.
• Create a new voucher.
• Save a voucher as Draft.
• Submit a voucher for approval.
• Edit or delete a voucher while it is in Draft status.
• Upload their signature (image upload).
• View only the vouchers created by themselves.
• View complete voucher details.
• Track the current status of their vouchers.
Employees should not be able to:
• View vouchers created by other employees.
• Approve or reject vouchers.
• Modify submitted, approved, or rejected vouchers.
3.2 Director (Admin)
The Director is responsible for approving or rejecting expense vouchers.
Director should be able to:
• Login to the application.
• View all vouchers.
• View pending approval requests.
• Search, filter, and sort vouchers.
• View voucher details.
• Approve vouchers.
• Reject vouchers.
• Upload their signature while approving a voucher.
• Provide a rejection reason while rejecting a voucher.
Director should not be able to:
• Modify the details entered by the employee.
3.3 Accounts Team
The Accounts Team is responsible for monitoring expense vouchers and processing
reimbursements.
Accounts Team should be able to:
• Login to the application.
• View all vouchers across the organization.
• Search, filter, and sort vouchers(Bonus Point).
• View voucher details.
• View employee and director signatures.
• View approval status.
• Download or print vouchers (optional).
Accounts Team should not be able to:
• Create vouchers.
• Edit vouchers.
• Delete vouchers.
• Approve or reject vouchers.

9. Validation Rules
The application shall enforce the following validations:
• Department is mandatory.
• Expense Title is mandatory.
• Expense Date is mandatory.
• Amount is mandatory.
• Amount must be greater than zero.
• Employee Signature is mandatory before submission.
• Director Signature is mandatory before approval.
• Rejection Reason is mandatory if a voucher is rejected.
10. Business Rules
1. Every voucher must have a unique Voucher Number.
2. Voucher Numbers should be generated automatically.
3. Every new voucher should initially be saved as Draft.
4. Employees may edit or delete vouchers only while they are in Draft status.
5. Once submitted, vouchers become read-only for employees.
6. Only the Director can approve or reject submitted vouchers.
7. Approved vouchers become read-only.
8. Rejected vouchers must include a rejection reason.
9. Employees can only view vouchers created by themselves.
10. The Director can view every voucher in the organization.
11. The Accounts Team can view every voucher in the organization.
12. Every submitted voucher must include the employee's signature.
13. Every approved voucher must include the Director's signature.
